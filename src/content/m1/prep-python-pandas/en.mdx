## Formulas

Simple return:

<Formula label="Relative change between adjacent prices">
r_t = P_t / P_(t-1) − 1
</Formula>

Cumulative NAV:

<Formula label="Compound returns into a NAV path">
NAV_T = ∏_(t=1)^T (1 + r_t)
</Formula>

## Python example (not a trading signal)

```python
import pandas as pd

# Synthetic closes: syntax only — not real data or a recommendation
px = pd.Series(
    [100.0, 101.0, 99.5, 100.5, 102.0],
    index=pd.bdate_range("2024-01-02", periods=5),
    name="close",
)

ret = px.pct_change()
nav = (1 + ret.fillna(0)).cumprod()
print(pd.DataFrame({"close": px, "ret": ret, "nav": nav}))
```

Teaching alignment: yesterday’s signal sizes today’s position:

```python
ma = px.rolling(3).mean()
raw_signal = (px > ma).astype(int)
position = raw_signal.shift(1).fillna(0)
gross = position * ret  # illustrative — not a tradable strategy
```
