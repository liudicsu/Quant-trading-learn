## 讲解

量化研究的第一步很少是复杂模型，而是把价格变成**可复现的收益序列**。对收盘价序列 `px`：

1. **简单收益**描述相邻两日相对变化  
2. **净值（NAV）**把收益连乘，便于看路径  
3. **信号与仓位**只用当时已知信息，否则回测会偷看未来

## 公式

简单收益：

<Formula label="相邻两期价格的相对变化">
r_t = P_t / P_(t-1) − 1
</Formula>

累计净值：

<Formula label="收益连乘得到净值路径">
NAV_T = ∏_(t=1)^T (1 + r_t)
</Formula>

## Python 示例（非交易信号）

```python
import pandas as pd

# 合成收盘价：演示语法，不是真实行情，更不是推荐标的
px = pd.Series(
    [100.0, 101.0, 99.5, 100.5, 102.0],
    index=pd.bdate_range("2024-01-02", periods=5),
    name="close",
)

ret = px.pct_change()
nav = (1 + ret.fillna(0)).cumprod()
print(pd.DataFrame({"close": px, "ret": ret, "nav": nav}))
```

教学上常用昨日信号决定今日仓位：

```python
ma = px.rolling(3).mean()
raw_signal = (px > ma).astype(int)
position = raw_signal.shift(1).fillna(0)
gross = position * ret  # 示意毛收益，不是可交易策略
```

<Callout type="warn" title="还不是策略">
没有交易成本、滑点与样本外评估。记住：信息时点对齐优先于把曲线画漂亮。
</Callout>
