## Learning goals

This lesson (~**16 hours**: 5h concepts + 9h labs + 2h write-up — **heavy**) builds backtest interrogation: cheat vs honest, grid overfitting, freeze-then-hold-out, and trial logging. Prereqs: `data-cleaning`, `stats-probability-basics`.

**Goals:** cheat/honest controls; OOS/walk-forward spirit; log failures and trial counts.

**Must-teach:** same-bar return without shift = look-ahead; many trials create false discoveries; freeze rules before OOS.

<Callout type="warn" title="Learning only">
Synthetic asset. Interrogate process — not stock tips.
</Callout>

## Parameters

- Asset AAA_adj; n≈299; Rf=0; ann √252  
- MA grid windows 5…40 step 5 (8 trials)  
- Hold-out: last **80** days; random-rule sweep 50 seeds × 30 trials, thr |SR|>1.5  

## Cheat vs honest MA

Same-bar (no shift) Sharpe can hit **~5.3** with NAV **~2.29**; honest `shift(1)` Sharpe is **negative**. Definition: today’s close in the signal earning today’s close-to-close return = look-ahead.

## Grid overfitting

The window that maximizes IS Sharpe often collapses OOS. Here best_train_w=35, train SR≈0.18, test SR≈−1.90.

## Freeze then hold-out

Select on a develop block, score a final window that never entered selection — sealed-evaluation spirit.

<Callout type="info" title="Sealed hold-out spirit (paper read)">
[Quant-Arena (arXiv:2610.30113)](https://arxiv.org/abs/2610.30113) lets models take feedback only on 2022–2023, then **freezes one strategy** for sealed 2024 assessment. This lesson practices the same discipline with develop→hold-out (a teaching simplification, not a reproduction of that benchmark).
</Callout>

## Trial counts and false hits

Across 50 seeds, mean count of |SR|>1.5 among 30 random rules ≈ **2.78** (std≈1.38) — noise looks “significant,” so log trials.

## Common mistakes / pitfalls

1. Treating same-bar fills as honest.  
2. Posting only the best grid curve.  
3. Tuning on the test set.  
4. No trial log.  
5. Leaking sealed-set feedback into R&D.
