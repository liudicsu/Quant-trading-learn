## 学习目标

本课（约 **10 学时**：概念 4h + 管线实验 5h + 文档/测验 1h）把「可版本化数据」做成习惯：哈希校验、幸存者偏差、PIT、时区错标前瞻、复权对照，并写数据说明书。前置：`eval-lab`。

**课内目标：** 版本化下载与哈希；举例幸存者偏差；写数据说明书。

**必须教会：** 今日成分 ≠ 历史宇宙；基本面需 PIT；时区混乱可前瞻一天。

## 参数

- 面板 `examples/p2/data/panel_toy.csv`，生成种子 **17**，n=300
- PIT 发布滞后 **5** 个交易日
- 复权对照：AAA 在 iloc 200 发生教学用 2:1 拆分

## 版本化与哈希

脚本计算 SHA-256 并与 `panel_toy.sha256` 对照。研究复现的第一步是：**同一字节 → 同一哈希**。

## 幸存者偏差（数例）

今日宇宙假设只剩 AAA/BBB，历史面板仍含 CCC。幸存者等权日均收益与全历史宇宙不同——用今日成分回放历史会美化存活者。

## PIT 基本面

`FUND_pit = FUND_true.shift(5)`。若用「当日已可知」的 `FUND_true` 对齐收益，等于偷看尚未发布的数字。

## 时区 / 会话错标

手算：把收盘价整体贴到「早一个交易日」的标签上，再对齐回真日历后，**周二那一行会拿到周三的收盘价**——这就是「错一天标签 ≈ 前瞻一天」。

## 复权 vs 未复权

拆分处 raw 收益约 **-50.8%**，adj 约 **-1.6%**。研究收益应明确用哪一套，并写进说明书。

## 延伸：数据入口（已阅读来源）

- [Binance Vision](https://data.binance.vision/) 提供可批量下载的历史行情文件；[sera00111 的工具笔记](https://x.com/sera00111/status/2108332340753969191)写到：分钟/小时级研究可先用 Vision 与 CCXT 等免费入口，先定策略再决定要不要买更细的订单簿数据。
- [OpenBB quantitative 文档](https://docs.openbb.co/odp/python/extensions/data-processing/quantitative) 说明 `obb.quantitative` 如何在**已对齐的**序列上做摘要/滚动/因子回归——它假设你先把数据时点弄对。
- [PyQuant News 的 API 举例帖](https://x.com/pyquantnews/status/2109990383828471949)（同线程还列了 yfinance、IBApi）把具体行情 API 点名列出，适合当「从哪拉数」的索引，而不是策略本身。

## 常见错误 / 陷阱

1. 用今日成分回测十年。  
2. 基本面不 PIT。  
3. UTC/本地日错一天。  
4. raw/adj 混用却不声明。  
5. 无哈希/无版本号。
