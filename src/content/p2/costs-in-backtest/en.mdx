## Learning goals

This lesson (~**6 hours**: 2h concepts + 3.5h coding + 0.5h quiz) wires commission/slippage into a formula and runs ≥3 cost tiers. Prereq: `backtest-traps`.

**Goals:** implement turnover cost formula; ≥3 cost tiers.

**Must-teach:** zero-cost curves ≠ live evidence; explicit vs implicit costs.

<Callout type="info" title="Learning only — not investment advice">
Toy bps. Not an exchange fee schedule.
</Callout>

## Parameters

- MA=10, `position=shift(1)`, Rf=0, √252  
- Formula: `net = pos*ret − turnover * one_way_bps/1e4`  
- Ladder: 0/5/10/20/40 bps  

## Explicit vs implicit

Explicit: commission-like bps you can write down. Implicit: spread/impact etc., approximated here by the same bps ladder — a reminder that some frictions remain unmodeled.

## Cost ladder

Even the zero-cost Sharpe is negative here; higher bps make Sharpe and NAV worse — turnover amplifies every step.

## Common mistakes / pitfalls

1. Posting zero-cost curves only.  
2. Ignoring turnover.  
3. Treating toy bps as official venue fees.  
4. Rewriting the signal after seeing costs (leakage).  
5. Not stating Rf/annualization.
