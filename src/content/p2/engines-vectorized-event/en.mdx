## Parameters

- MA=10; Rf=0; market orders fill at **next open**; open = prior close for the match test  
- Stop demo: **3%** from entry; range proxy = min(open, close)

Same-bar close NAV ≈ **2.29** (optimistic). Next-open / `shift(1)` ≈ **0.818**. Silent same-bar defaults inflate results.

## When you need an event engine

Use events when the fill depends on **intrabar path** or **state**:

- **Stop-loss / take-profit / limits** (fill price ≠ close)  
- **Multiple assets** with staggered fills / partials  
- **Capital / margin / risk checks** before send  

Lab stop demo: stop_exits=**1**, NAV with stop ≈ **0.821** vs no-stop **0.818**. A single close-to-close vector cannot place the fill at the stop without an intrabar rule.

## Common mistakes / pitfalls

1. Treating a library name as an assumptions sheet.  
2. Vectorized same-bar defaults.  
3. Claiming a close-only vector “has stops” without an intrabar rule.  
4. Reading future bars inside handle_data.  
5. Comparing engines without matching fill conventions.
