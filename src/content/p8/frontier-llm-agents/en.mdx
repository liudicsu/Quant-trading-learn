## RD-Agent(Q) (read the paper)

[R&amp;D-Agent-Quant / RD-Agent(Q)](https://arxiv.org/abs/2505.15155) is a **data-centric multi-agent** framework for factor–model co-optimization. It splits work into a **Research** stage (goal-aligned prompts, hypotheses → tasks) and a **Development** stage that implements and feeds results back. Microsoft’s [RD-Agent](https://github.com/microsoft/RD-Agent) repo is the engineering home. Automation **multiplies** hypotheses — so purged OOS, costs, and DSR(N) get *more* important, not less.

Lab `examples/p8/01_llm_agents_offline.py` mocks the loop with a formula bank + IS keep rule (`mean_CS_IC > 0.01`). That rule **keeps noise** alongside the weak true factor — exactly the overfitting story.

## Sealed hold-out (Quant-Arena spirit)

[Quant-Arena](https://arxiv.org/abs/2610.30113) (Qian et al.) benchmarks whether LLM agents can finish the research loop and still work **beyond** the research period. Teach the protocol: research only on 2022–2023 with a bounded candidate budget; **freeze** one strategy; open sealed year **2024 once**; no re-mining after a peek. Lab prints sealed OOS IC for `agent_kept` vs `honest_slow`.

**Verified negative leaderboard punchline (re-read Table 2 / abstract):** no model’s *best-scoring* sealed-2024 configuration beat the gross equal-weight market (~**17.1%** ARR). The top-scored run (GPT-6 Astra) returned ~**10.7%** ARR (excess ≈ **−6.3** pp). One non–top-scored Sol medium config prints ~18.4% — **a number above equal-weight, but not that model’s top-score row; not advantage evidence**. Sealed hold-out + costs turn many “AI quant” demos into a caution.

<Callout type="warn" title="Reject: “AI hedge fund / always-profitable LLM”">
Marketing that implies an LLM agent is always profitable fails this sealed, costed protocol. Scoreboards without freeze-then-sealed-year are not evidence.
</Callout>

Stable companion: [LLM+MCTS formulaic mining](https://arxiv.org/abs/2505.11122) — still subject to the same interrogation.

## AlphaAgent — originality, complexity, hypothesis alignment

[AlphaAgent](https://arxiv.org/abs/2502.16789) (Tang et al., KDD ’25) argues LLM factor miners **homogenize** toward crowded classics (RSI/momentum/value/size) unless regularized. Three mechanisms: (i) **originality** via AST similarity vs an alpha zoo; (ii) **hypothesis–factor alignment** (LLM-scored semantic consistency); (iii) **complexity control** (AST length / parameter count). Code reference: [RndmVariableQ/AlphaAgent](https://github.com/RndmVariableQ/AlphaAgent). Lab prints a toy Jaccard-vs-zoo foil: a clone scores high overlap; a structurally novel expression scores lower — **originality ≠ edge**. You still need purge, DSR(N), and sealed OOS. Crowding link: see P4 `factor-workflow`.

## Parametric look-ahead (weights remember the future)

[FinCAD paper](https://arxiv.org/abs/2605.24564) (Li, Wang, Ma) names **parametric look-ahead bias**: an LLM pretrained through year *T* may encode how named tickers moved in years *&lt; T* **inside its weights** — invisible to PIT data audits. **Teach the PROBLEM:** for any LLM-as-decision claim overlapping the training window, prefer **post-cutoff / sealed-year** evaluation only. **FinCAD recipe = NAME-ONLY footnote** (inference-time CAD attenuation); this course does not implement it.

## CogAlpha — NAME-ONLY map

[CogAlpha](https://arxiv.org/abs/2511.18850) (code-based evolutionary LLM alpha mining) sits next to RD-Agent / AlphaAgent on the map. Shared traps: trial inflation, homogenization, leaky eval, paper metrics ≠ sealed costs/DSR. **Out of scope:** Deep RL / FinRL-as-alpha, HFT latency recipes, options market-making.

## LLM sentiment (Lopez-Lira &amp; Tang 2023)

[Can ChatGPT Forecast Stock Price Movements?](https://arxiv.org/abs/2304.07619) (Lopez-Lira &amp; Tang): under a **post-cutoff** design the authors report a predictive **association** with reactions/drift — that is **not** “use ChatGPT to trade,” and the reported edge shrinks as adoption rises. Lab builds offline `mock_sentiment` (PIT) vs a **LEAK** foil (cutoff/memorization analogue). LEAK IC ≈ +0.67 is a warning, not a strategy. Later critiques tighten the same point: [Glasserman &amp; Lin (arXiv:2309.17322)](https://arxiv.org/abs/2309.17322); [Lopez-Lira, Tang &amp; Zhu (arXiv:2504.14765)](https://arxiv.org/abs/2504.14765) on memorization / non-identification.

## Five LLM-finance sins + structural validity checklist

[Evaluating LLMs in Finance Requires Explicit Bias Consideration](https://arxiv.org/abs/2602.14233) (Kong et al.) names five recurring **sins** that create an illusion of validity:

1. **Look-ahead** — future info in weights or RAG at historical \(t\)
2. **Survivorship** — delisted / failed names silently dropped
3. **Narrative** — fluent story not supported by evidence available at \(t\)
4. **Objective** — confident completion rewarded over calibrated abstention
5. **Cost** — gross metrics with zero trading friction and zero inference cost

Among 164 main-conference papers (2023–2025) they reviewed, **no single bias is discussed in more than ~28%** of studies (look-ahead ≈26.8%). Treat the following as **pass/fail gates** before any deployment claim:

| Gate | Fail if… |
|------|----------|
| Temporal sanitation | Any prompt / RAG / tool uses post-\(t\) info |
| Dynamic universe | Universe is end-of-sample survivors only |
| Rationale robustness | Explanations are untested decoration |
| Epistemic calibration | Forced guesses; abstention never scored |
| Realistic costs & latency | Primary metric is frictionless gross PnL |

Lab prints the same checklist offline.

## Long-horizon LLM timing under bias-mitigated eval (debunk FinMem / FinAgent marketing)

[Can LLM-based Financial Investing Strategies Outperform the Market in Long Run?](https://arxiv.org/abs/2505.07078) (Li, Kim, Cucuringu, Ma; FINSABER) shows short, selective windows (often &lt;1 year, &lt;10 symbols) **overstate** LLM timing agents such as FinMem / FinAgent. Under broader / longer, bias-mitigated composites, Buy-and-Hold and simple rules often win on risk-adjusted metrics; agents can be too timid in bulls and too aggressive in bears.

Lab selective-window foil:

```text
selective_best_~6m_SR≈4.079  full_sample_SR≈0.191  buy_hold_SR≈-0.027
delta_selective_minus_full≈+3.889
```

<Callout type="warn" title="Reject: FinMem / FinAgent-style marketing on tiny windows">
A glowing 3–6 month backtest on a handful of mega-cap winners is **not** long-run evidence. Demand FINSABER-style breadth, delist-aware universes, and risk-adjusted metrics.
</Callout>

## OpenPM — audit protocol spirit (NAME use, not PnL)

[OpenPM](https://arxiv.org/abs/2608.09988) is an **auditable point-in-time** evaluation framework for LLM portfolio agents: availability-gated records, contamination certificates, cost-sensitivity curves, and a deterministic mandate critic. **Teach the protocol**, not a PnL claim — returns without leakage / cost / mandate audits are upper bounds, not validated alpha.

## Common mistakes / pitfalls

- **Training cutoff / memorization:** pre-cutoff headlines are not forecasts; LEAK foils look amazing (see Glasserman &amp; Lin 2309.17322; Lopez-Lira/Tang/Zhu 2504.14765).
- **Parametric look-ahead:** weights can remember in-cutoff ticker paths (2605.24564) — sealed-year / post-cutoff only.
- **Homogenized LLM factors:** without originality/complexity/hypothesis constraints, signals crowd and decay (AlphaAgent).
- **Trial inflation:** agent rounds need explicit **N** in DSR; paper tables ≠ your sealed OOS.
- **IS keep rules** overfit; sealed years must stay sealed.
- **Withdrawn papers:** Chain-of-Alpha — use live banner + admin comment; drop unstable claims.
- **Scope reject:** Deep RL / FinRL-as-alpha, HFT latency, options MM — out of this curriculum.
- Niche motivation only: XQuant Spec+AI run-first (@_zheergen) — still needs the same traps.
