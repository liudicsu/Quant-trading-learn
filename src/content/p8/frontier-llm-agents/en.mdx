## Learning goals

This lesson (~**8 hours**: 4h guided reading + 3h critical exercises + 1h rules rewrite) treats **LLM / multi-agent quant R&D** as a *frontier* under the same anti-leakage and multiple-testing discipline as P4–P5 — never as a shortcut. Prereqs: `factor-workflow`, `ml-leakage-control`, `modern-ml-pipelines`, `compliance-ethics`.

**Goals:** state the RD-Agent(Q) loop; list LLM factor-mining failure modes; design a sealed-OOS acceptance bar.

**Must-teach:** automation amplifies trials → stricter multiple testing; paper metrics ≠ your reproducible edge; agent outputs enter the same trap interrogation.

## RD-Agent(Q) (read the paper)

[R&amp;D-Agent-Quant / RD-Agent(Q)](https://arxiv.org/abs/2505.15155) (NeurIPS 2025) is a **data-centric multi-agent** framework for factor–model co-optimization. It splits work into a **Research** stage (goal-aligned prompts, hypotheses → tasks) and a **Development** stage that implements and feeds results back. Microsoft’s [RD-Agent](https://github.com/microsoft/RD-Agent) repo is the engineering home. Automation **multiplies** hypotheses — so purged OOS, costs, and DSR(N) get *more* important, not less.

Lab `examples/p8/01_llm_agents_offline.py` mocks the loop with a formula bank + IS keep rule (`mean_CS_IC > 0.01`). That rule **keeps noise** alongside the weak true factor — exactly the overfitting story.

## Sealed hold-out (Quant-Arena spirit)

[Quant-Arena](https://arxiv.org/abs/2610.30113) benchmarks whether LLM agents can finish the research loop and still work **beyond** the research period. Teach the protocol: **freeze** the factor list after IS; open a sealed year **once**; no re-mining after a peek. Lab prints sealed OOS IC for `agent_kept` vs `honest_slow`.

Stable companion: [LLM+MCTS formulaic mining](https://arxiv.org/abs/2505.11122) — still subject to the same interrogation.

## LLM sentiment (Lopez-Lira &amp; Tang 2023)

[Can ChatGPT Forecast Stock Price Movements?](https://arxiv.org/abs/2304.07619) (Lopez-Lira &amp; Tang) shows GPT scores on **post-knowledge-cutoff** headlines can predict reactions/drift — and that edge shrinks as adoption rises. Lab builds an offline `mock_sentiment` (PIT) vs a **LEAK** foil that peeks at next returns (cutoff/memorization analogue). LEAK IC ≈ +0.67 is a warning, not a strategy. Later critiques make the same point rigorous: [Glasserman &amp; Lin (arXiv:2309.17322)](https://arxiv.org/abs/2309.17322) measure look-ahead vs distraction via headline anonymization; [Lopez-Lira, Tang &amp; Zhu (arXiv:2504.14765)](https://arxiv.org/abs/2504.14765) prove pre-cutoff “forecasts” are non-identified under memorization.

## Limitations / failure modes

- **Training cutoff / memorization:** pre-cutoff headlines are not forecasts; LEAK foils look amazing (see Glasserman &amp; Lin 2309.17322; Lopez-Lira/Tang/Zhu 2504.14765).
- **Trial inflation:** agent rounds need explicit **N** in DSR; paper tables ≠ your sealed OOS.
- **IS keep rules** overfit; sealed years must stay sealed.
- **Withdrawn papers:** Chain-of-Alpha — cite existence + withdrawal, drop unstable claims.
- Niche motivation only: XQuant Spec+AI run-first (@_zheergen) — still needs the same traps.
