## 学习目标

本课（约 **8 学时**：导读 4h + 批判练习 3h + 守则改写 1h）把 **LLM / 多智能体量化研发**当作 *前沿*：必须服从与 P4–P5 相同的防泄漏与多重检验纪律，绝不是捷径。前置：`factor-workflow`、`ml-leakage-control`、`modern-ml-pipelines`、`compliance-ethics`。

**课内目标：** 陈述 RD-Agent(Q) 闭环；列出 LLM 挖因子失败模式；设计密封样本外验收。

**必须教会：** 自动化放大试错 → 更需多重检验；论文指标 ≠ 你的可复现优势；Agent 输出须进同一陷阱审讯。

<Callout type="info" title="仅供学习 — 非投资建议">

</Callout>

## 参数

- 合成截面：40 资产 × 520 日；弱潜因子 + 滞后 `slow` 驱动
- Agent IS 窗口 400 日；**密封 OOS** 末 120 日（冻结后只打开一次）
- 主指标：**日均截面 RankIC**；DSR 带**显式 N**；共享成本（10 bps + 冲击）
- Mock 代替 LLM；公式库 =「Development」产物

## RD-Agent(Q)（已读论文）

[R&amp;D-Agent-Quant / RD-Agent(Q)](https://arxiv.org/abs/2505.15155)（NeurIPS 2025）是面向因子–模型联合优化的**数据中心多智能体**框架：将流程拆成 **Research**（目标对齐提示、假设→任务）与 **Development**（实现并反馈）。工程主页见 Microsoft [RD-Agent](https://github.com/microsoft/RD-Agent)。自动化**放大**假设数量——因此 purge OOS、成本与 DSR(N) 更重要，而非更次要。

实验 `examples/p8/01_llm_agents_offline.py` 用公式库 + IS 保留规则（`mean_CS_IC > 0.01`）模拟闭环。该规则会把**噪声**和弱真因子一起留下——正是过拟合故事。

![Mock RD-Agent 提案](/p8/rdagent_proposals.png)

## 密封 hold-out（Quant-Arena 精神）

[Quant-Arena](https://arxiv.org/abs/2610.30113) 检验 LLM agent 能否跑完研究闭环且在研究期**之外**仍有效。协议：IS 结束后**冻结**因子列表；密封年**只打开一次**；偷看后再挖无效。实验打印 `agent_kept` 与 `honest_slow` 的密封 OOS IC。

稳定对照：[LLM+MCTS 公式化挖掘](https://arxiv.org/abs/2505.11122)——同样要过陷阱审讯。

## LLM 情绪（Lopez-Lira &amp; Tang 2023）

[Can ChatGPT Forecast Stock Price Movements?](https://arxiv.org/abs/2304.07619)（Lopez-Lira &amp; Tang）表明：在**知识截止日期之后**的标题上，GPT 分数可预测反应/漂移——且随采用上升收益下降。实验构造离线 `mock_sentiment`（PIT）与窥视下一收益的 **LEAK** 对照（截止日期/记忆类比）。LEAK IC ≈ +0.67 是警告，不是策略。后续批判把同一问题写严：[Glasserman &amp; Lin（arXiv:2309.17322）](https://arxiv.org/abs/2309.17322) 用标题匿名化度量前瞻 vs 分心；[Lopez-Lira、Tang &amp; Zhu（arXiv:2504.14765）](https://arxiv.org/abs/2504.14765) 证明截止前「预测」在记忆下不可识别。

## 局限 / 失败模式

- **训练截止 / 记忆：** 截止前标题不是预测；LEAK 对照会显得很美（见 Glasserman &amp; Lin 2309.17322；Lopez-Lira/Tang/Zhu 2504.14765）。
- **试错膨胀：** agent 轮次必须在 DSR 中写明 **N**；论文表 ≠ 你的密封 OOS。
- **IS 保留规则**过拟合；密封年必须保持密封。
- **已撤回论文：** Chain-of-Alpha — 只记存在+撤回，不写进流水线。
- Niche 动机仅参考：XQuant Spec+AI（@_zheergen）——仍要同一套陷阱。
