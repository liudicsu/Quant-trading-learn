## 学习目标

本课（约 **16 学时**：导读 5h + 批判练习 6h（五宗罪/FINSABER/OpenPM）+ 守则改写 2h + 密封排行榜 3h）把 **LLM / 多智能体量化研发**当作 *前沿*：必须服从与 P4–P5 相同的防泄漏与多重检验纪律，绝不是捷径。前置：`factor-workflow`、`ml-leakage-control`、`modern-ml-pipelines`、`compliance-ethics`。

**课内目标：** 陈述 RD-Agent(Q) 闭环；解释 AlphaAgent 正则；列出 LLM 挖因子失败模式；设计密封样本外验收。

**必须教会：** 自动化放大试错 → 更需多重检验；论文指标 ≠ 你的可复现优势；Agent 输出须进同一陷阱审讯；参数前瞻须用截止后/密封年主张。

<Callout type="info" title="仅供学习 — 非投资建议">
仅 **离线 mock**。运行时不调用 ChatGPT/Claude/任何付费 API。实验从不实盘下单。
</Callout>

## 参数

- 合成截面：40 资产 × 520 日；弱潜因子 + 滞后 `slow` 驱动
- Agent IS 窗口 400 日；**密封 OOS** 末 120 日（冻结后只打开一次）
- 主指标：**日均截面 RankIC**；DSR 带**显式 N**；共享成本（10 bps + 冲击）
- Mock 代替 LLM；公式库 =「Development」产物

## RD-Agent(Q)（已读论文）

[R&amp;D-Agent-Quant / RD-Agent(Q)](https://arxiv.org/abs/2505.15155) 是面向因子–模型联合优化的**数据中心多智能体**框架：将流程拆成 **Research**（目标对齐提示、假设→任务）与 **Development**（实现并反馈）。工程主页见 Microsoft [RD-Agent](https://github.com/microsoft/RD-Agent)。自动化**放大**假设数量——因此 purge OOS、成本与 DSR(N) 更重要，而非更次要。

实验 `examples/p8/01_llm_agents_offline.py` 用公式库 + IS 保留规则（`mean_CS_IC > 0.01`）模拟闭环。该规则会把**噪声**和弱真因子一起留下——正是过拟合故事。

## 密封 hold-out（Quant-Arena 精神）

[Quant-Arena](https://arxiv.org/abs/2610.30113)（Qian 等）检验 LLM agent 能否跑完研究闭环且在研究期**之外**仍有效。协议：仅在 2022–2023 研究、候选预算有界；**冻结**一条策略；密封年 **2024 只打开一次**；偷看后再挖无效。实验打印 `agent_kept` 与 `honest_slow` 的密封 OOS IC。

**已核验负面排行榜结论（重读摘要/表2）：** 没有任何模型的*最高总分*密封-2024 配置跑赢全市场等权（毛收益 ARR 约 **17.1%**）。最高分那次（GPT-6 Astra）约 **10.7%** ARR（超额约 **−6.3** 个百分点）。另有 Sol medium 配置数字约 18.4%——**高于等权、但不是最高总分行；不作优势证据**。密封 hold-out + 成本常把「AI 量化」演示变成警示。

<Callout type="warn" title="拒绝：「AI 对冲基金 / 永远盈利的 LLM」">
暗示 LLM agent 总盈利的营销话术，过不了该密封、含成本协议。没有「冻结再测密封年」的排行榜不是证据。
</Callout>

稳定对照：[LLM+MCTS 公式化挖掘](https://arxiv.org/abs/2505.11122)——同样要过陷阱审讯。

## AlphaAgent — 原创性、复杂度、假设对齐

[AlphaAgent](https://arxiv.org/abs/2502.16789)（Tang 等，KDD ’25）指出：若不加正则，LLM 挖因子会**同质化**到拥挤经典（RSI/动量/价值/规模）。三机制：(i) 相对 alpha zoo 的 **AST 原创性**；(ii) **假设–因子对齐**（语义一致性）；(iii) **复杂度控制**。代码参考：[RndmVariableQ/AlphaAgent](https://github.com/RndmVariableQ/AlphaAgent)。实验打印玩具 Jaccard：克隆表达式重叠高、结构新颖者更低——**原创 ≠ 优势**。仍须 purge、DSR(N)、密封 OOS。拥挤桥接见 P4 `factor-workflow`。

## 参数前瞻（权重记住未来）

[FinCAD 论文](https://arxiv.org/abs/2605.24564) 命名 **parametric look-ahead**：预训练到年份 *T* 的 LLM，可能在**权重内**编码 *T* 之前的行情——PIT 数据审计看不见。**先教问题：** 与训练窗重叠的 LLM 决策主张，优先只用**截止后/密封年**评估。**FinCAD 配方 = 仅点名脚注**（本课不实现）。

## CogAlpha — 仅点名

[CogAlpha](https://arxiv.org/abs/2511.18850)（代码级进化式 LLM 挖 alpha）与 RD-Agent / AlphaAgent 并列地图。共享陷阱：试错膨胀、同质化、泄漏评估、论文指标 ≠ 密封成本/DSR。**范围外：** Deep RL / FinRL-as-alpha、HFT 时延、期权做市。

## Chain-of-Alpha — 已核验撤回

[Chain-of-Alpha](https://arxiv.org/abs/2508.06312) **在 arXiv 上存在**，但已**撤回**。本会话抓取的 abs 横幅原文：**“This paper has been withdrawn by Lang Cao”**。同页管理员评论：**“This version has been removed by arXiv administrators as the submitter did not have the rights to agree to the license at the time of submission.”** **放弃双链细节主张**；不依赖不稳定 PDF。**忽略仍在展示「跑赢」表格的 HTML/PDF 镜像**——以 abs 撤回横幅为准。优先 RD-Agent(Q)、AlphaAgent、LLM+MCTS、Quant-Arena。

## LLM 情绪（Lopez-Lira &amp; Tang 2023）

[Can ChatGPT Forecast Stock Price Movements?](https://arxiv.org/abs/2304.07619)（Lopez-Lira &amp; Tang）：在**截止后**设计下，作者报告 GPT 分数与反应/漂移存在预测性**关联**——这**不是**「拿 ChatGPT 去交易」，且随采用上升该关联会变弱。实验构造离线 `mock_sentiment`（PIT）与 **LEAK** 对照。LEAK IC ≈ +0.67 是警告，不是策略。后续批判把同一问题写严：[Glasserman &amp; Lin（arXiv:2309.17322）](https://arxiv.org/abs/2309.17322)；[Lopez-Lira、Tang &amp; Zhu（arXiv:2504.14765）](https://arxiv.org/abs/2504.14765)（记忆/不可识别）。

## 金融 LLM 五宗罪 + 结构有效性清单

[Evaluating LLMs in Finance Requires Explicit Bias Consideration](https://arxiv.org/abs/2602.14233)（Kong 等）点名五种反复出现、制造「看起来有效」幻觉的 **罪**：

1. **前瞻** — 历史 \(t\) 时权重或 RAG 用到未来信息  
2. **幸存者** — 默默丢掉退市/失败标的  
3. **叙事** — 流畅故事并无 \(t\) 时可获得证据支撑  
4. **目标** — 奖励自信填空，而非校准的弃权  
5. **成本** — 毛收益假设零摩擦、零推理成本  

他们审阅的 164 篇主会论文（2023–2025）中，**没有任何单一偏差被超过约 28% 的论文讨论**（前瞻 ≈26.8%）。部署主张前把下列项当作 **通过/失败门**：

| 门禁 | 失败条件 |
|------|----------|
| 时间净化 | 提示 / RAG / 工具用到 \(t\) 之后信息 |
| 动态股票池 | 股票池只含样本期末幸存者 |
| 理由稳健 | 解释只是未检验的装饰 |
| 认知校准 | 强迫猜测；弃权从不计分 |
| 真实成本与时延 | 主指标是无摩擦毛 PnL |

实验离线打印同一清单。

## 长区间 LLM 择时：偏差缓解评估下的劣势（拆穿 FinMem / FinAgent 营销）

[Can LLM-based Financial Investing Strategies Outperform the Market in Long Run?](https://arxiv.org/abs/2505.07078)（Li、Kim、Cucuringu、Ma；FINSABER）表明：短且挑剔的窗口（常 &lt;1 年、&lt;10 只标的）会**夸大** FinMem / FinAgent 一类 LLM 择时代理。在更宽、更长、偏差缓解的组合评估下，买入持有与简单规则常在风险调整指标上更好；代理可能在牛市过保守、熊市过激进。

实验选择性窗口对照：

```text
selective_best_~6m_SR≈4.079  full_sample_SR≈0.191  buy_hold_SR≈-0.027
delta_selective_minus_full≈+3.889
```

<Callout type="warn" title="拒绝：FinMem / FinAgent 式小窗口营销">
在少数大市值赢家上漂亮的 3–6 个月回测 **不是** 长期证据。要求 FINSABER 式广度、含退市池与风险调整指标。
</Callout>

## OpenPM — 审计协议精神（仅点名用法，不当 PnL）

[OpenPM](https://arxiv.org/abs/2608.09988) 是面向 LLM 组合代理的 **可审计点时**评估框架：可用性门控、污染证书、成本敏感曲线、确定性约束批评器。**教协议，不教收益表**——缺泄漏/成本/约束审计的收益只是上界，不是已验证 alpha。

## 常见错误 / 陷阱

- **训练截止 / 记忆：** 截止前标题不是预测；LEAK 对照会好看得吓人（Glasserman &amp; Lin；Lopez-Lira/Tang/Zhu）。
- **参数前瞻：** 权重可记住截止前路径（2605.24564）——只用密封年/截止后。
- **同质化 LLM 因子：** 缺原创/复杂度/假设约束会拥挤衰减（AlphaAgent）。
- **试错膨胀：** DSR 须显式 **N**；论文表 ≠ 密封 OOS。
- **IS 保留规则**过拟合；密封年必须保持密封。
- **已撤回论文：** Chain-of-Alpha — 用现场横幅+管理员评论；不写进流水线。
- **范围拒绝：** Deep RL / FinRL-as-alpha、HFT 时延、期权做市 — 本课大纲外。
- Niche 仅动机：XQuant Spec+AI（@_zheergen）。
