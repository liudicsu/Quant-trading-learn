## 学习目标

本课（约 **14 学时**：AFML 概念 5h + 实验 7h + 写作 2h — 重课）建立金融 **防泄漏 ML**：标签、带 embargo 的 purged CV、仅训练集拟合的 scaler，以及过拟合陷阱。前置：`factor-workflow`、`backtest-traps`。

**课内目标：** 演示 shuffle 泄漏；时间切分与因果特征；用 IC 而非准确率评价。

**必须教会：** 失败常在管线；禁止时序 shuffle；完整 purged K-fold + embargo（AFML ch.7）；scaler 仅 fit 训练折；远期/三重势垒/元标签（AFML ch.3）并检查前瞻；用 IC / 净 SR / DSR 打分。

<Callout type="info" title="学习用途 — 非投资建议">
使用 P4 **弱**面板（`MU_WEAK=0.001`）抽样 50 只。数字用来说明管线漏洞——不是实盘 ML 优势。
</Callout>

## 参数

- 面板：P4 弱，**50** 资产 × 750 日；`HORIZON=5`；`N_FOLDS=5`；`EMBARGO=5`
- 特征（时点 `t`）：`mom_1/5/10/20`、`vol_5/20`、`rank_mom20`，仅用 ≤ `t` 的收益
- 标签：远期求和 `t+1..t+h`；三重势垒 `pt=sl=0.02`、垂直 `h`；相对 `sign(mom_20)` 的元标签
- 演示模型：Ridge；过拟合陷阱 = `HistGradientBoostingRegressor` + 40 噪声特征
- 评价：**RankIC**（非准确率）

## 标签（AFML ch.3）

**远期收益：** `fwd_ret[t] = sum(rets[t+1..t+h])`。

**三重势垒：** 从 `t+1` 起走路径；触及 +pt / −sl 或垂直 `h`。

**元标签：** 主模型方向来自 `mom_20[t]`；`meta_y=1` 当且仅当与势垒结果同向（做/不做）。

**前瞻审计：** 特征止于 `t`；势垒只读未来路径作为 `y`；随后 purge 去掉标签跨度与测试块重叠的训练行。

## 泄漏控制（AFML ch.7）

| 协议 | RankIC（实验） | 角色 |
|------|----------------|------|
| Shuffle 切分 | ≈0.062 | **泄漏** — 禁止 |
| 全局 scaler（训+测） | ≈0.010 | **泄漏** 模式 |
| 未 purge 的打乱 KFold | ≈0.065 | **泄漏** — 标签重叠 |
| 仅训练 scaler + 时间切分 | ≈0.010 | 更干净 |
| **Purged K-fold + embargo** | ≈−0.008 | **干净** |
| 扩展 walk-forward | ≈0.015 | **干净** |

Purge 去掉标签跨度 `[t+1,t+h]` 与测试块重叠的训练时点；embargo 再去掉测试结束后的 `EMBARGO` 根 K 线。Scaler **只**在训练折上 fit。

![泄漏 vs 干净](/p5/leak_vs_clean_ic.png)

## 过拟合陷阱

深度 GBM + **40 个噪声特征**：训练 RankIC ≈ **0.40**，OOS RankIC ≈ **0.01**。高样本内 IC 不是优势——记下试验次数。

![过拟合陷阱](/p5/overfit_trap_ic.png)

## 期望值框架

弱面板上诚实的 purged IC 接近 0 才是正确答案。Shuffle/未 purge CV 抬高的 IC 是**管线海市蜃楼**，与 P2 回测陷阱同族。

## 前瞻警告

- 特征不得吃进同 bar 标签。
- Scaler 不得看见测试折。
- CV 不得保留与测试时段标签重叠的训练样本。
- 元标签若势垒跨过折边界仍需 purge。

## 常见错误 / 陷阱

1. 打乱时序面板行。
2. 在全样本上 fit StandardScaler。
3. 不做 purge/embargo 的 sklearn KFold。
4. 为噪声深度树的训练 IC 欢呼。
5. 用准确率代替 IC / 净 SR。
