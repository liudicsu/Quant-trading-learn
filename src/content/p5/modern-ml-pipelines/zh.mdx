## SFI 与 MDI / MDA / SHAP 并列（AFML 第8章）

**替代效应：** 相关特征（**mom_20** 与 **mom_20_dup**）会拆分 MDI/MDA/SHAP 的功劳。**单特征重要性（SFI）**换一个问题：在同一 purged 协议下，每个特征**单独**有多好？

实验折-2 单变量 ridge SFI（日度截面 RankIC）：`mom_20`≈**+0.0185**，`mom_20_dup`≈**+0.0145**——单独几乎相当，因而是**替代品**，不是两个独立 alpha。用 SFI 补全 MDI/MDA/SHAP，避免重复计功。

![SFI](/p5/sfi_importance.png)

## Localformer / Transformer 对照箔（同一 purged 协议）

**可选对照，不是颁奖台。** Microsoft **Qlib**（Yang 等，arXiv:2009.11189）的 Alpha158 基准包含 **Transformer**（Vaswani 等，2017）与 **Localformer**（Qlib 带局部性偏置的 Transformer 变体；见 Qlib benchmarks / 相关 Jiang 等工作）。本站**不**重训这些权重，而是在**同一** purged 折、RankIC、成本与 DSR 纪律下跑一个**小型因果注意力池化 + ridge 对照箔**。

| 模型 | 日度截面 RankIC 均值 | 说明 |
|------|----------------------|------|
| purged ridge | ≈**+0.040** | 线性基线 |
| purged GBM | ≈+0.034 | 树基线 |
| 注意力池化 ridge 箔 | ≈**−0.010** | 此处**未**击败基线 |

**教学：** 诚实协议下，“Transformer 风味”头**不会**自动获胜。引用 Qlib 公开的 Localformer/Transformer 数字仅作**可选对照**——绝不是跳过 purge、embargo 或成本的许可证。**不宣称“深度学习必胜”。**

## 常见错误 / 陷阱

1. 头条用混合 Spearman 而非日度截面 IC。
2. 看见净夏普为负就断言“无信号”，而截面 IC 仍约 +0.04。
3. 不做替代效应检查。
4. 用未校准概率下注。
5. 神话零样本 TSFM。
6. 把重复特征上的 MDI 质量读成两个独立 alpha（跳过 SFI）。
7. 未在同一 purged 协议与成本下就宣称 “Localformer/Transformer 获胜”。
