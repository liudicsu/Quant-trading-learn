## 学习目标

本课（约 **8 学时**：架构 3h + 小流水线 4h + 可选 Qlib 1h）搭建**可复现 ML 量化流水线**：purged CV 下 ridge vs GBM、重要度（MDI/MDA/SHAP）、校准与下注，以及 Qlib 风格 Alpha158 + LGBModel 的 pandas 镜像。前置：`ml-leakage-control`、`data-cleaning`。

**课内目标：** 特征→模型→预测→简单组合草图；先树/线性再深度；可选阅读 Qlib 工作流。

**必须教会：** 可版本化流水线重于花哨模型；Qlib Data/Model/Portfolio/Analysis；MDI/MDA/SHAP 与替代效应；校准 + AFML ch.10 下注；公开数据≠优势；零样本 TSFM 常弱于树模型（已核验论文）。

## 参数

- Purged OOF：`N_FOLDS=5`，`HORIZON=5`，`EMBARGO=5`；仅训练 `StandardScaler`
- 模型：Ridge（`alpha∈{0.01,1,100}`）；LightGBM（回退 HistGBM）
- 组合：截面五分位多空 + 共享 P2/P4 成本
- DSR：Bailey–LdP，`n_trials=4`（= 尝试的配置数）
- SHAP：若可 import 则使用（否则如实说明）

## Ridge vs GBM（IC / 净 SR / DSR）

| 配置 | RankIC | 净夏普 | DSR |
|------|--------|--------|-----|
| ridge | ≈−0.008 | ≈−0.38 | ≈0.00 |
| lightgbm | ≈0.011 | ≈−1.47 | ≈0.00 |
| ridge α=0.01 / 100 | ≈−0.008 | ≈−0.38 / −0.39 | ≈0.00 |

**不是准确率。** 弱面板上 purged OOS IC 接近 0，成本使净夏普 ≤ 0——流水线仍尽了本分。

## 特征重要度与替代效应

在 purged 训练折上拟合；MDA 在 purged 测试折上计算。加入 `mom_20_dup = mom_20 + noise`。

实验：MDI 在 `mom_20` 与 `mom_20_dup` 之间**分摊**（替代效应）。MDA/SHAP 同样分功——相关重复会稀释单特征分数。

## 校准与下注（AFML ch.10）

元标签概率来自逻辑回归（purged OOF）。可靠性曲线：原始 vs **isotonic**（Platt/logit 亦常见）。仓位 ∝ `(2p−1)+` × 主方向——用**校准后**概率下注，而非原始分数。

![校准](/p5/calibration_reliability.png)

## Qlib 风格工作流（pandas）

官方文档：`Alpha158` → `DatasetH` → `LGBModel.fit` → `SignalRecord`（[模型文档](https://qlib.readthedocs.io/en/latest/component/model.html)）。

pandas 镜像：特征栈 ≈ Alpha158；purged 片段 ≈ DatasetH；LightGBM/Ridge ≈ LGBModel；`pred_to_ls_pnl` ≈ 由分数做组合。本课引用文档并镜像阶段——不要求本地安装 Qlib。

## 前沿：TSFM / Transformer（已核验）

**引用**而非重训以下 2024–2026 评价（已核 arXiv）：

- **arXiv:2511.18578** *Re(Visiting) Time Series Foundation Models in Finance* — 零样本 Chronos/TimesFM 在日超额收益上弱于 CatBoost/LightGBM；微调常难填平差距。
- **arXiv:2412.09880** *Financial Fine-tuning a Large Time Series Model* — 基线 TimesFM 在价格预测上表现不佳，需金融持续预训练。
- **arXiv:2606.27100** *Pretrained Time-Series Foundation Models for Financial Return Forecasting* — 或有排名优势，相对随机游走的增益小且稀疏。

**LLM 智能体留到 P8。** 任何深度序列模型仍须同一套防泄漏协议。

## 期望值框架

在弱面板上报告接近 0 的 purged IC 的可版本化流水线，比未 purge、准确率漂亮的 GBM 更有价值。带显式 `n_trials` 的 DSR 让配置挑选保持诚实。

## 常见错误 / 陷阱

1. 靠准确率或训练损失选模型。
2. 忽略跨 alpha/树的 DSR / 试验数。
3. 不做相关重复检查就读 MDI。
4. 用未校准概率下注。
5. 不读金融评价就把零样本 TSFM 当免费 alpha。
