## 参数

- α = 0.05 VaR/CVaR；回看 `L = 252`；MC：5000 条按滞后窗标定的 Student-t(5) 路径
- 日 t 的 VaR 只用到 `t−1` 的收益
- 回撤规则作用在**受控**账本：软 10% / 硬 20%（滞后）；软硬之间线性降仓
- 集中度：`w_i ≤ 0.30`；总杠杆 ≤ 1.5
- Kupiec LR ~ χ²(1) 检验违约次数

## VaR 与 CVaR（滞后）

- **历史：** 过去窗口 α 分位的相反数
- **参数：** −(μ + σ Φ⁻¹(α))，同一滞后窗
- **MC：** 从厚尾示意（Student-t）模拟，再读 VaR/CVaR
- **CVaR / ES：** 超过 VaR 阈值的平均损失（Artzner 等 1999 推动相干风险；此处 CVaR 作实务 ES 对照）

实验：均值历史 VaR ≈ 0.027，均值 CVaR ≈ 0.034；MC_t5 VaR ≈ 0.030，CVaR ≈ 0.042。**仅在两者皆有限的交易日上**计算时，**CVaR ≥ VaR 检查率 = 1.00**（热身期 NaN 必须排除——若对含 NaN 的布尔比较做 `nanmean`，会把假阴性与无效日混在一起，误报成约 0.83；并非「并列/空尾」）。

## Kupiec 违约回测

Kupiec（1995，*Journal of Derivatives* 3(2)）给出违约率是否等于名义 α 的似然比检验（**无条件覆盖**）。实验 n = 1247：

| 模型 | 违约次数 | 比率 | LR | p 值 |
|------|----------|------|----|------|
| 历史 95% | 73 | 0.0585 | 1.82 | 0.177 |
| 参数 95% | 67 | 0.0537 | 0.36 | 0.550 |

本路径上常规水平未拒绝 α = 5%——仍要报告检验，不能把「未拒绝」当成保证。

## Christoffersen 条件覆盖 + 巴塞尔交通灯（计数，不是交易）

Kupiec 只问「违约次数对不对」。[Christoffersen（1998），*International Economic Review* 39(4)](https://www.jstor.org/stable/2527392) 再问：**违约会不会扎堆**。

- **LR_uc**：无条件覆盖（与 Kupiec 同精神）— 平均违约率是否 ≈ α。
- **LR_ind**：独立性 — 今天违约是否会抬高明天违约的概率（聚类）。
- **恒等式：** `LR_cc = LR_uc + LR_ind`，在正确条件覆盖下约服从 **χ²(2)**。

实验巴塞尔窗 `n=250`、违约 `x=21`（目标 α=0.05）：

| 统计量 | 数值 | 说明 |
|--------|------|------|
| LR_uc | **5.097**（p≈0.024） | 平均频率偏高 |
| LR_ind | **0.463**（p≈0.496） | 本路径上未见强聚类 |
| LR_cc | **5.560**（χ²(2) p≈**0.062**） | UC+IND；检查 `LR_cc ≈ LR_uc+LR_ind` |

**巴塞尔交通灯**把（经典 **99%** VaR 的）违约次数划进绿/黄/红**计数带宽**——给监管/审计看例外有多密，**不是**择时或 alpha 信号。本玩具窗是 95% 教学映射：`x=21` 会落在「红」一侧，仍**禁止**据此下单。

<Callout type="warn" title="排伪">
绿/黄/红 = 审计计数。不要把交通灯当成买卖信号。
</Callout>

## 压力测试

等权玩具账本情景 PnL：股票 −10% → −5.25%；利率 +100bp 代理 → −3.25%；波动冲击且相关→1 → −8.0%。压力**不是**概率——是董事会级叙事检查。

## 回撤控制（滞后）

用受控权益至 t−1 的回撤决定 t 的敞口。实验：未控最大回撤 ≈ −0.75 → 受控 ≈ −0.20（硬熔断）。深层路径后规则保持部分降仓，平均敞口下降——这正是刹车的意义。

## 集中度与杠杆上限

投影原始权重：截断 `w_i ≤ 0.30`，再归一，再把总敞口压到 ≤ 1.5。实验账本满足 max_w ≤ 0.30 且投影后 gross = 1.0。

## 缺口分析与密钥卫生

每条限额 → 负责人、指标、触发动作、滞后数据源。密钥：笔记本不写 API key；轮换；最小权限；纸面与实盘凭证分离；提交前扫描。

## 前瞻警告

- 勿把当日收益放进当日 VaR 窗口
- 回撤熔断必须用昨日权益高水位
- 压力冲击是假想——不要当成已实现 alpha 回填

## 常见错误 / 陷阱

1. VaR 窗口含当日收益（前瞻）。
2. 把 VaR 当成损失*承诺*而非模型下的分位数。
3. 因为「看起来还行」就跳过 Kupiec / 违约日志。
4. 回撤规则读到明日权益。
5. 把 `.env` / API key 和笔记本一起提交。
