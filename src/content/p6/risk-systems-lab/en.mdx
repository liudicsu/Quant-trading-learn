## Parameters

- α = 0.05 VaR/CVaR; lookback `L = 252`; MC: 5000 Student-t(5) paths calibrated to lagged window
- Day-t VaR uses returns through `t−1` only
- DD rule on the **controlled** book: soft 10% / hard 20% (lagged); linear de-risk between soft and kill
- Concentration: `w_i ≤ 0.30`; gross leverage ≤ 1.5
- Kupiec LR ~ χ²(1) on exception counts

## VaR and CVaR (lagged)

- **Historical:** −quantile_α of the past window
- **Parametric:** −(μ + σ Φ⁻¹(α)) from the same lagged window
- **MC:** simulate from a fat-tailed foil (Student-t), read VaR/CVaR from the simulated loss distribution
- **CVaR / ES:** mean loss beyond the VaR threshold (Artzner et al. 1999 motivate coherent risk measures; CVaR is the practical ES foil here)

Lab: mean hist VaR ≈ 0.027, mean CVaR ≈ 0.034; MC_t5 VaR ≈ 0.030, CVaR ≈ 0.042. **CVaR ≥ VaR check = 1.00** when computed only over days where both estimates are finite (NaN warm-up days must be excluded — a naive `nanmean(cvar>=hvar)` wrongly mixes False with NaN comparisons).

## Kupiec exception backtest

Kupiec (1995, *Journal of Derivatives* 3(2)) gives a likelihood-ratio test for whether the exception rate equals the nominal α (**unconditional coverage**). Lab on n = 1247:

| Model | exceptions | rate | LR | p-value |
|-------|------------|------|----|---------|
| historical 95% | 73 | 0.0585 | 1.82 | 0.177 |
| parametric 95% | 67 | 0.0537 | 0.36 | 0.550 |

Neither rejects α = 5% at conventional levels on this path — still report the test, do not treat a non-reject as a guarantee.

## Stress tests

Scenario PnL on a toy equal book: equity −10% → −5.25%; rates +100bp proxy → −3.25%; vol-spike corr→1 → −8.0%. Stress is **not** a probability — it is a board-level narrative check.

## Drawdown control (lagged)

Decide exposure at t from controlled equity DD through t−1. Lab: uncontrolled max DD ≈ −0.75 → controlled max DD ≈ −0.20 (hard kill). Mean exposure falls because the rule stays partially de-risked after deep paths — that is the point of a brake.

## Concentration and leverage limits

Project raw weights: clip `w_i ≤ 0.30`, renormalise, then scale gross to ≤ 1.5. Lab books satisfy max_w ≤ 0.30 and gross = 1.0 after projection.

## Gap analysis and secrets hygiene

Map each limit → owner, metric, breach action, lagged data source. Secrets: no API keys in notebooks; rotate; least privilege; separate paper vs live credentials; scan before commit.

## Look-ahead warnings

- Never compute today’s VaR with today’s return in the window
- DD brakes must use yesterday’s equity high-water
- Stress shocks are hypothetical — do not backfill them as if they were realised α

## Common mistakes / pitfalls

1. Same-day returns inside the VaR window (look-ahead).
2. Treating VaR as a loss *promise* rather than a quantile under a model.
3. Skipping Kupiec / exception logs because “it looks fine.”
4. DD rule that reads tomorrow’s equity.
5. Committing `.env` / API keys with the notebook.
