## 学习目标

建立研究前的金融常识：现货 / 期货 / ETF 的直觉差别，多头与空头、杠杆如何放大盈亏路径，单利与复利净值，以及为什么评价需要**可投资、可复现的基准**。若你已能清楚解释这些概念，可通过测验跳过。本课讲的是**研究流程语言**，不是荐股或下单教程。

<Callout type="warn" title="非投资建议">
不推荐任何标的或杠杆水平。杠杆示例忽略融资成本，仅作教学玩具。
</Callout>

## 直觉

- **现货**：直接持有（或券商记账的）标的本身；盈亏大致跟价格走。  
- **期货**：标准化远期合约，有到期与保证金；价格发现与对冲常用，但机制比「买股票」多一层。  
- **ETF**：一篮子敞口的基金份额，常被选作**可交易基准**的近似。  
- **多头**：价格涨往往有利；**空头**：价格跌往往有利（还需借券/保证金等摩擦——此处只留 Imp。）。  
- **杠杆**：同样的价格波动，账户权益波动被放大；路径依赖更强，回撤更痛。  
- **基准**：你声称「有超额」时，必须说清相对谁；基准应尽可能可投资、可复现，而不是事后挑一个好看的曲线。

**无免费午餐**：更高的期望收益通常伴随着某种风险、成本或隐性约束。

## 公式

单期简单收益 r_t。  
**复利净值**（从 1 起）：

<Formula label="复合净值">
NAV_T = ∏_(t=1)^T (1 + r_t)
</Formula>

**算术累计（单利式示意）**：1 + \sum r_t——教学对比用，不是市场默认结算方式。  
**杠杆玩具**（忽略融资）：\(NAV_L_T = product (1 + L * r_t)\)。

## 手算小例子

两期收益 +10\%, −10\%：

- 复利：1.1 × 0.9 = 0.99（亏 1%）  
- 若有人用「平均收益 0」误判无事，会忽略路径。

## Python 实验（已本地运行）

脚本：`examples/p0/03_basic_finance.py`。

```python
import pandas as pd
rets = pd.Series([0.01, -0.02, 0.015, 0.01, -0.005])
simple_nav = 1 + rets.cumsum()
compound_nav = (1 + rets).cumprod()
lev_nav = (1 + 2.0 * rets).cumprod()  # 2x，无融资成本
```

终值：不加杠杆复利净值约 **1.00962**；2x 玩具约 **1.01846**。注意：真实杠杆还有融资、强平与缺口风险，**不能**把该终值差当成「应加杠杆」的证据。

## 常见错误 / 陷阱

1. 把期货/ETF 当成「就是缩小版股票」而忽略到期、折溢价、跟踪误差。  
2. 谈论空头时忘记摩擦与挤空风险（本课只要求意识到「不对称」）。  
3. 用单利对比广告复利产品，或反过来。  
4. 基准事后挑选（data snooping）。  
5. 把教学杠杆玩具外推成仓位建议。
