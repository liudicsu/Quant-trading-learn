## Learning goals

Build pre-research finance literacy: intuitive differences among spot, futures, and ETFs; how long/short and leverage reshape P&amp;L paths; simple versus compound NAV; and why evaluation needs an **investable, reproducible benchmark**. If you can already explain these cleanly, test out. This lesson teaches **research vocabulary**, not stock tips or order placement.

<Callout type="warn" title="Not investment advice">
No recommendations of names or leverage. The leverage toy ignores financing costs.
</Callout>

## Intuition

- **Spot** — exposure to the instrument itself (broker books aside); P&amp;L roughly tracks price.  
- **Futures** — standardized forwards with expiry and margin; extra mechanics versus “buy shares.”  
- **ETFs** — fund shares on a basket; often used as a **tradable benchmark** proxy.  
- **Long** benefits when prices rise; **short** when prices fall (locate/borrow frictions exist — awareness only here).  
- **Leverage** amplifies equity swings; paths hurt more in drawdowns.  
- **Benchmark** — “alpha” is relative; prefer investable, reproducible benchmarks chosen up front.

**No free lunch**: higher expected return usually pairs with risk, cost, or hidden constraints.

## Formulas

Per-period simple return r_t.  
**Compound NAV** from 1:

<Formula label="Compound equity">
NAV_T = ∏_(t=1)^T (1 + r_t)
</Formula>

**Arithmetic cumulation (simple-style teaching contrast):** 1 + \sum r_t.  
**Leverage toy** (no financing): \(NAV_L_T = product (1 + L * r_t)\).

## Worked numeric example

Returns +10\% then −10\%: compound finish 1.1 × 0.9 = 0.99. A “zero average return” story misses path dependence.

## Python lab (run locally)

Script: `examples/p0/03_basic_finance.py`.

```python
import pandas as pd
rets = pd.Series([0.01, -0.02, 0.015, 0.01, -0.005])
simple_nav = 1 + rets.cumsum()
compound_nav = (1 + rets).cumprod()
lev_nav = (1 + 2.0 * rets).cumprod()  # 2x, no financing
```

## Common mistakes / pitfalls

1. Treating futures/ETFs as tiny stocks while ignoring expiry, premium/discount, tracking error.  
2. Discussing shorts without frictions/squeeze asymmetry.  
3. Mixing simple and compound storytelling in comparisons.  
4. Choosing benchmarks after seeing results.  
5. Promoting the teaching leverage toy as a sizing advice.
