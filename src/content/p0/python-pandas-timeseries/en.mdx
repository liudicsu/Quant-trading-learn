## Intuition: time index is first-class

If you align finance tables by row number alone, tomorrow’s price can silently land on today’s signal. A `DatetimeIndex` forces the question: which session does this row represent? When two series merge, do they align by date or by position?

**Misalignment = silent lookahead**: using tomorrow’s close to decide today’s position makes backtests pretty and research false.

## Formulas

Simple return:

<Formula label="Relative change between adjacent closes">
r_t = P_t / P_(t-1) − 1
</Formula>

Simple moving average of length w:

<Formula label="Rolling mean">
MA_t(w) = (P_t + P_(t-1) + … + P_(t−w+1)) / w
</Formula>

## Worked numeric example

Closes 100, 101, 100.5:

- r_2 = 101/100 - 1 = 0.01
- r_3 = 100.5/101 - 1 ≈ -0.00495
- MA_3 on day 3: (100+101+100.5)/3 = 100.5

## 1. read_csv into a DatetimeIndex

Bundled CSV: `examples/p0/data/synthetic_ohlc.csv` (12 synthetic business days of OHLC).

```python
import pandas as pd

raw = pd.read_csv(CSV)
ohlc = raw.copy()
ohlc["date"] = pd.to_datetime(ohlc["date"])

assert isinstance(ohlc.index, pd.DatetimeIndex)

```

## 2. reindex / align worked example

Series `a` keeps every close; series `b` drops two dates. `join="inner"` keeps the intersection; `join="outer"` keeps the union with `NaN` on the missing side.

```python
a = ohlc["close"].rename("a")
b = a.drop(a.index[[2, 5]]).rename("b")
inner = pd.concat([a, b], axis=1, join="inner")
outer = pd.concat([a, b], axis=1, join="outer")
```

Lab output: `a_len 12`, `b_len 10`, `inner_rows 10`, `outer_rows 12` with `outer_null_b 2`. Row-number merges would silently pair 2024-01-04’s `a` with the wrong `b`.

## 3. Missing values: dropna / ffill / interpolate

Plant two `NaN` closes (iloc 3 and 7), then compare methods:

| Method | Meaning | Main cost |
| --- | --- | --- |
| `dropna` | Drop missing days | Shorter sample; rolling windows shift |
| `ffill` | Forward-fill last print | **Invented quotes** on halt days |
| `interpolate(method="time")` | Time interpolation | Invents a smooth path — still not real volume |

Printed mean returns: `dropna≈0.006005`, `ffill≈0.004913`, `interpolate≈0.004909`. There is no universal “correct” fill — choose for the research question and document it.

## Common mistakes / pitfalls

1. **Blind `ffill` after `reindex`**: fake prints on halt days pollute returns.
2. **Row-number merges instead of date align**: silent calendar skew.
3. **Row loops that ignore the session calendar**: prefer vectorized ops; still audit `NaN`s.
4. **Multiplying an unshifted signal by same-day returns**: classic lookahead.
5. **No asserts**: object dtypes and duplicate dates fail far downstream.
