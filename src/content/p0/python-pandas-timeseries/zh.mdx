## 直觉：时间索引是第一公民

金融表如果只按「第几行」对齐，就很容易把**明天的价格**不小心接到今天的信号上。`DatetimeIndex` 强迫你显式回答：这一行代表哪个交易日？两个序列合并时，是按日期对齐，还是按位置硬拼？

**错位 = 隐性前瞻（lookahead）**：例如用「明日收盘」判断「今日该不该持仓」。回测曲线会变漂亮，但研究结论是假的。

## 公式

简单收益：

<Formula label="相邻收盘价的相对变化">
r_t = P_t / P_(t-1) − 1
</Formula>

长度为 w 的简单移动平均：

<Formula label="滚动均值">
MA_t(w) = (P_t + P_(t-1) + … + P_(t−w+1)) / w
</Formula>

## 手算小例子

取三天收盘 100, 101, 100.5：

- r_2 = 101/100 - 1 = 0.01
- r_3 = 100.5/101 - 1 ≈ -0.00495
- MA_3 在第三天：(100+101+100.5)/3 = 100.5

## 1. 从 CSV 读入并设 DatetimeIndex

仓库已附带小 CSV：`examples/p0/data/synthetic_ohlc.csv`（12 个交易日合成 OHLC）。

```python
import pandas as pd

raw = pd.read_csv(CSV)
ohlc = raw.copy()
ohlc["date"] = pd.to_datetime(ohlc["date"])
ohlc = ohlc.set_index("date").sort_index()
assert isinstance(ohlc.index, pd.DatetimeIndex)
print(ohlc.head())
```

## 2. reindex / align 工作实例

两条不完全重合的日历：序列 `a` 用完整收盘；序列 `b` 故意丢掉两天。`join="inner"` 只留交集；`join="outer"` 保留并集并在缺失侧出现 `NaN`。

```python
a = ohlc["close"].rename("a")
b = a.drop(a.index[[2, 5]]).rename("b")
inner = pd.concat([a, b], axis=1, join="inner")
outer = pd.concat([a, b], axis=1, join="outer")
```

本课脚本输出：`a_len 12`、`b_len 10`、`inner_rows 10`、`outer_rows 12` 且 `outer_null_b 2`。按行号硬拼会把 2024-01-04 的 `a` 错配到别的 `b`——这就是静默错位。

## 3. 缺失值处理：dropna / ffill / interpolate

在收盘上故意插入两处 `NaN`（iloc 3 与 7），分别用三种方法处理后再算收益均值：

| 方法 | 含义 | 主要代价 |
| --- | --- | --- |
| `dropna` | 丢掉缺失日 | 样本变短，滚动窗口对齐改变 |
| `ffill` | 用前一有效值填 | **发明假报价**（停牌日假装有成交） |
| `interpolate(method="time")` | 按时间插值 | **用到之后才知道的价格填空（前瞻）**；绝不能喂给信号；回测里只允许 ffill 或丢行 |

脚本打印的均值收益：`dropna≈0.006005`，`ffill≈0.004913`，`interpolate≈0.004909`。`interpolate(method="time")` 会同时使用**缺口两侧（含更晚）**的已知价，因此是 **look-ahead**：演示可以，**绝不能**把插值结果送进信号；回测里只允许 `ffill`（仅用过去）或丢行（`dropna`）。

## 常见错误 / 陷阱

1. **`reindex` 后盲目 `ffill`**：把停牌空档填成假成交价，再算收益。
2. **`interpolate(method="time")` 当信号输入**：它用**更晚**的已知价填缺口，是前瞻；回测只许 `ffill` 或丢行。
3. **按行号 merge 而不是按日期 align**：不同日历会静默错位。
4. **行循环改价格却忘记交易日历**：优先向量化，但仍要检查 `NaN` 位置。
5. **信号未 `shift` 就乘当日收益**：经典 lookahead。
6. **不写断言**：dtype 变成 object、重复日期索引，错误拖到很后面才爆。
