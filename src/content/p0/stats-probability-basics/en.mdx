## Intuition

- **Mean** centers; **variance/std** spreads. Financial returns are often heavy-tailed, so “mean ± 1 std” is not the whole story.  
- **Quantiles** (5%/95%) speak about tails without assuming normality.  
- **Correlation** summarizes linear co-movement; short samples are noisy; rolling correlation drifts.  
- **IID often fails** in markets: volatility clusters; regimes break.  
- **Many trials**: among 100 random rules, a few will look great in-sample — that is multiple comparison, not discovery.

## Formulas

Sample variance with (n-1) degrees of freedom:

<Formula label="Unbiased sample variance">
s^2 = sum_i (x_i - mean)^2 / (n - 1)
</Formula>

Std s = sqrt(s^2).  
A teaching Sharpe (zero rf) on daily returns:

<Formula label="Annualized Sharpe sketch">
Sharpe ≈ mean(r) / std(r) * sqrt(252)
</Formula>

## Worked numeric example

Returns 0.01, -0.02, 0.015: mean ≈ 0.00167; sample variance uses sum of squared deviations over 2; std is the square root.

## Python lab (run locally)

Script: `examples/p0/02_stats_probability.py` (fixed numpy seed, offline).

```python
import numpy as np, pandas as pd
rng = np.random.default_rng(42)
n = 252
r_a = pd.Series(rng.normal(0.0004, 0.01, n), index=pd.bdate_range("2023-01-02", periods=n))
r_b = 0.3 * r_a + pd.Series(rng.normal(0, 0.01, n), index=r_a.index)
# 100 trials: random sign positions; count |Sharpe|>2
```

## Common mistakes / pitfalls

1. Treating one lucky in-sample Sharpe as a repeatable edge.  
2. Assuming IID normality despite clustered volatility.  
3. Confusing variance with std (different units).  
4. Estimating correlation on tiny windows without uncertainty.  
5. Reading correlation as causation.
