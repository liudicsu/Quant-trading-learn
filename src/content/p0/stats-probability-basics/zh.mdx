## 直觉

- **均值**描述中心，**方差/标准差**描述离散；金融收益常厚尾，均值±1 倍标准差并不能覆盖「大部分故事」。
- **分位数**（如 5%/95%）直接谈尾部，不依赖正态假设。
- **相关**只是线性共变的摘要；样本短时噪声大，滚动相关会漂移。
- **IID（独立同分布）在金融里常常不成立**：波动聚集、结构性断点。标准教科书里的 p 值公式若默认 IID，会**高估**显著性（AFML 反复强调：在金融数据上机械套用会误导）。
- **多次试错**：你试 100 个随机规则，总会撞上几个「看起来夏普很高」的幸运儿——这不是发现，是多重比较；把样本内最好结果当成可上线策略，就是 **backtest overfitting**（AFML 精神）。

## 公式

样本方差（(n-1) 自由度）：

<Formula label="无偏样本方差">
s^2 = sum_i (x_i - mean)^2 / (n - 1)
</Formula>

样本标准差 s = sqrt(s^2)。  
日频收益夏普的一种教学写法（未扣无风险利率）：

<Formula label="年化夏普示意">
Sharpe ≈ mean(r) / std(r) * sqrt(252)
</Formula>

当样本量 n=252 时，检验「均值是否为 0」的 t 统计量 mean/(std/sqrt(n)) 在数值上等于上述夏普示意——这只是教学巧合，方便对照，不是定义等价。

## 为何要同时看分位与波动

只看均值会被几天大涨大跌带走；方差/标准差描述「散得有多开」，分位数则直接回答「很差的 5% 日子大概多差」。实盘研究里三者一起看，比只报一个夏普更诚实。

## p 值误用：数值走读

参数（与脚本一致）：**n=252** 日，年化因子 **√252**，阈值 **|SR|>2**，多重检验演示种子 **7**，每次 **100** 条随机符号规则。

在原假设下，若日频主动收益近似 IID 且 SR_ann = mean/std×√252 的标准差约等于 1，则 **P(|Z|>2)≈4.55%**，即每 100 次大约应有 **4–5** 次越过阈值。种子 **7** 是偏极端的一次抽取，给出了 **10** 次（见下方多种子扫描：200 个种子的均值约 **4.40**、标准差约 **2.15**，而种子 7 打到了扫描中的最大值 10）。

原假设 H0：某条「随机符号仓位」规则的日均盈亏均值为 0。  
在这 **100** 次里挑出 |Sharpe| 最大的一次，再算双侧正态近似 p 值——本课输出约 **p≈0.0013**，|Sharpe|≈3.22。

若你**只展示这一次**并宣称「p 小于 0.01，策略显著」，就是误用：显著性预算没有为「已搜索 100 条规则」付账。这正是多重检验 / 回测过拟合要打的脸（AFML）。诚实做法至少包括：事先登记假设、报告试验次数、样本外或组合惩罚。

## 完整多重检验循环（课内展示）

固定：`n=252`，`Sharpe = mean/std*sqrt(252)`，阈值 `|Sharpe|>2`，演示种子 `7`（另见脚本对 200 个种子的扫描）。


```python
rng_mt = np.random.default_rng(7)
false_hits = 0
sharpes = []
for i in range(100):
    noise = rng_mt.normal(size=n)
    pos = np.sign(noise)
    pnl = pos * r_a.values
    sh = sharpe(pd.Series(pnl))  # mean/std*sqrt(252)
    sharpes.append(sh)
    if abs(sh) > 2:
        false_hits += 1
print("trials", 100)
print("false_hits_|Sharpe|>2", false_hits)
print("max_abs_sharpe", round(max(abs(s) for s in sharpes), 3))
```

## 常见错误 / 陷阱

1. 把**一次**漂亮的样本内夏普（或小 p 值）当成可重复优势。
2. 默认收益 **IID 正态**，忽视波动聚集（与 AFML 警告同向）。
3. 混淆**方差与标准差**（量纲不同）。
4. 用很短窗口估计相关，却不报告不确定性。
5. 相关当因果：两资产同涨同跌可能只是共同风险因子。
6. 搜索上千参数后只贴最好曲线——经典 backtest overfitting。
