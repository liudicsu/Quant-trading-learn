## 学习目标

在已会 pandas 时间序列的前提下，建立收益研究的统计直觉：均值/方差/分位数、相关与样本噪声，以及「试很多次会看到假显著」的多重比较问题。若你已熟悉分布、相关、p 值误用与多重检验，可测验跳过。

<Callout type="info" title="学习用途">
合成随机数实验，不是实盘策略评估，更不是荐股。
</Callout>

## 直觉

- **均值**描述中心，**方差/标准差**描述离散；金融收益常厚尾，均值±1 倍标准差并不能覆盖「大部分故事」。  
- **分位数**（如 5%/95%）直接谈尾部，不依赖正态假设。  
- **相关**只是线性共变的摘要；样本短时噪声大，滚动相关会漂移。  
- **IID（独立同分布）在金融里常常不成立**：波动聚集、结构性断点。  
- **多次试错**：你试 100 个随机规则，总会撞上几个「看起来夏普很高」的幸运儿——这不是发现，是多重比较。

## 公式

样本方差（(n-1) 自由度）：

<Formula label="无偏样本方差">
s^2 = sum_i (x_i - mean)^2 / (n - 1)
</Formula>

样本标准差 s = sqrt(s^2)。  
日频收益夏普的一种教学写法（未扣无风险利率）：

<Formula label="年化夏普示意">
Sharpe ≈ mean(r) / std(r) * sqrt(252)
</Formula>

## 为何要同时看分位与波动

只看均值会被几天大涨大跌带走；方差/标准差描述「散得有多开」，分位数则直接回答「很差的 5% 日子大概多差」。实盘研究里三者一起看，比只报一个夏普更诚实。

## 手算小例子

三点收益 0.01, -0.02, 0.015：

- 均值 \bar r = 0.001666…  
- 先算偏差平方再除以 2 得样本方差（约 0.000358），标准差约 0.0189。

## Python 实验（已本地运行）

脚本：`examples/p0/02_stats_probability.py`（`numpy` 固定种子，离线）。

```python
import numpy as np, pandas as pd
rng = np.random.default_rng(42)
n = 252
r_a = pd.Series(rng.normal(0.0004, 0.01, n), index=pd.bdate_range("2023-01-02", periods=n))
r_b = 0.3 * r_a + pd.Series(rng.normal(0, 0.01, n), index=r_a.index)
# 100 次：用随机符号当仓位，数 |Sharpe|>2 出现次数
```

## 常见错误 / 陷阱

1. 把**一次**漂亮的样本内夏普当成可重复优势。  
2. 默认收益 **IID 正态**，忽视波动聚集。  
3. 混淆**方差与标准差**（量纲不同）。  
4. 用很短窗口估计相关，却不报告不确定性。  
5. 相关当因果：两资产同涨同跌可能只是共同风险因子。
