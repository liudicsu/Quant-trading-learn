## Net-of-cost table (highlights)

Buy-and-hold gross Sharpe≈0.66; toy MA net Sharpe≈0.39 at 0 bps, ≈0.19 at 5 bps, and **turns negative at 15 bps**. Annualized one-way turns ≈ **49** — costs scale with turnover.

## Win-rate trap

**Win-rate definition (this lesson):** `win_rate_all_days` = share of **all** days with `pnl>0` (flat/zero days count as non-wins). Not “days-in-position only.”

### Pointer — base-rate-honest directional accuracy

Raw “80% directional accuracy” ads can be a **bull-market base rate**: an **always-up** rule scores high with zero skill. Headline excess accuracy = model accuracy − always-up accuracy on the **same** windows ([arXiv:2607.12248](https://arxiv.org/abs/2607.12248)). Full foil + lab live in `frontier-tsfm-altdata-crypto`; here just remember: win rate and raw direction both need an honest baseline.

Seed=3 toy path: win rate≈**0.91** but **negative** mean return. High win rate can hide rare large losses.

<Callout type="info" title="Risk-adjusted traits (@FG731314)">
A [post by @FG731314](https://x.com/FG731314/status/2115609441748001008) on “good gold quant strategy” traits stresses (1) **clear logic** you can state in one sentence — not a mystical curve — and (2) **risk-adjusted returns that hold up** (Sharpe/Calmar/max drawdown/payoff), not annualized return alone. That matches this lesson: **net risk-adjusted** metrics beat win rate or gross-only charts.

## PyFolio tear-sheet meaning (reuse your metrics)

**Intuition:** A [PyFolio](https://github.com/quantopian/pyfolio) / pyfolio-reloaded **returns tear sheet** is a dashboard, not a new edge. `create_returns_tear_sheet(returns, benchmark_rets=...)` plots and tables numbers you already met in `returns-vol-corr` and this lab.

| Tear-sheet label | Lab value (5 bps toy) | How you already compute it |
|------------------|-----------------------|----------------------------|
| Annual return | ≈+0.025 | mean(daily)×252 |
| Annual volatility | ≈0.126 | std(daily)×√252 |
| Sharpe (Rf=0) | ≈0.195 | (mean−Rf)/std×√252 |
| Max drawdown | ≈−0.092 | min(nav/peak−1) |
| Cumulative return | ≈+0.017 | final NAV − 1 |
| Daily VaR 5% | ≈−0.015 | empirical 5th percentile |
| Stability (R²) | ≈0.34 | R² of log-NAV vs time |

**Teach:** read full-sample vs OOS carefully; still apply cost honesty; only attach a benchmark when it is investable and time-aligned. Run: `examples/p1/04_eval_lab.py`.

## Common mistakes / pitfalls

1. Posting gross curves only.
2. Using win rate instead of expectancy and drawdown.
3. Ignoring turnover×cost linkage.
4. No benchmark comparison.
5. Evaluating “net of cost” without shifting the signal (still mixed with look-ahead).
6. Treating a tear sheet as proof of edge instead of a metric dashboard.
7. Attaching a misaligned or non-investable “benchmark” series.
