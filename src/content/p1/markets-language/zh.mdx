## 学习目标

本课（约 **5 学时**：概念 2h + 练习 2.5h + 测验 0.5h）建立交易研究语言：假设→信号→风险→归因，区分 **Alpha / Beta**，列出市场摩擦，并把 CSV 收盘变成收益与净值。前置：`basic-finance-markets`。

**课内目标：** 三句话研究目标；区分 Alpha/Beta；列出市场摩擦。

**必须教会：** 主目标是**约束下的风险调整后表现**；程序员优势在工程化研究链；策略必须可复现。

## 直觉：研究链

一条可辩护的研究陈述通常是：

1. **假设**（可证伪）→ 2. **信号**（信息时点明确）→ 3. **风险/约束** → 4. **归因**（相对何基准、是否扣成本）。

程序员的优势往往不在「灵光一现的公式」，而在把上述链条做成**可版本化、可复现**的流水线。

## Alpha 与 Beta（数值例子）

**Beta**：与基准共变的部分。  
**Alpha**：扣掉 Beta×基准之后的残差均值（教学里常年化为 ×252）。

脚本用已知 DGP：`true_alpha_daily=0.0001`，`true_beta=1.2`，`n=251`，`seed=11`，`Rf=0`。估计得到 `beta_hat≈1.22`，`alpha_hat_ann≈0.084`（样本噪声下不会精确等于真值）。

<Formula label="教学 OLS">
beta = cov(r, r_m) / var(r_m);  alpha_d = mean(r) − beta * mean(r_m)
</Formula>

**前瞻风险：** OLS 用的是已对齐的同期收益；不要把 `shift(-1)` 的价格偷进信号再谈 Alpha。

## 市场摩擦清单

至少五条（脚本打印了六条）：买卖价差、佣金、滑点/冲击、借券/融资、延迟成交、税费（视市场）。忽略摩擦的「毛收益」叙事不诚实——P1 末课会量化。

## 三句话研究目标（模板）

脚本给出可复现模板：**市场/样本 → 约束与年化约定 → 成功标准（净夏普/回撤、冻结样本外）**。目标必须可检验，不能是「看起来聪明」。

## CSV→收益→净值

数据：`examples/p1/data/synthetic_ohlc_ba.csv`（生成种子 11，n=252）。

```python
raw = pd.read_csv(CSV, parse_dates=["date"]).set_index("date")
ret = raw["close"].pct_change()
nav = (1 + ret.fillna(0)).cumprod()  # day-1 fill 0 仅为净值路径教学
```

参数：`Rf_daily=0`。终值净值约 **1.106**。

## 常见错误 / 陷阱

1. 把「绝对收益高」当成目标，却不谈约束与回撤。  
2. 把 Beta 暴露说成 Alpha。  
3. 不写摩擦清单就宣称可实盘。  
4. 研究不可复现（无种子、无 CSV、无版本）。  
5. 用未来收益定义今日信号（lookahead）。
