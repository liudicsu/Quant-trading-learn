## 美国主线：PDT 继任规则 — 四个日期 + 迁移状态

**直觉：** 一条规则「已生效」不等于「你的券商、你的账户已经切换」。FINRA 给了会员迁移期，所以要把**日期**和**会员迁移状态**分成两个维度记录。

| 事项 | 日期（[FINRA 26-10](https://www.finra.org/rules-guidance/notices/26-10)，2026-11-08 核实） |
|------|------|
| SEC 批准（Release 34-105226） | 2026-04-14 |
| Notice 发布 | 2026-04-20 |
| 规则生效 | 2026-06-04 |
| 会员迁移期截止 | 2027-10-20 |

新的日内保证金标准**整体取代**旧的 PDT 次数认定与 $25,000 最低权益要求；[26-11](https://www.finra.org/rules-guidance/notices/26-11)（2026-05-19 发布、2026-06-04 生效）给出 IML/IMD 解释。普通维持保证金并未消失。

**版本练习的正确写法（按审阅报告 R04）：** FINRA 示例分别记录 SEC 批准日、Notice 发布日期、规则生效日、迁移期截止日，并加入 `member_adoption_date` / `broker_checked_on` 与适用账户类别。2026-06-04 至 2027-10-20 期间，不得只凭交易日期断言某会员/账户已迁移；迁移状态未知时输出 `needs_broker_verification`。不得由本地 toy 给出法律合规保证。

```python
def pdt_regime(trade_date: str, member_adoption_date: str | None) -> str:
    if trade_date < "2026-06-04":
        return "old_pdt"
    if member_adoption_date is None:
        return "needs_broker_verification" if trade_date <= "2027-10-20" else "intraday_margin"
    return "intraday_margin" if trade_date >= member_adoption_date else "old_pdt"
```

## 美国 — 市场接入、卖空、保证金、算法督导

### SEC Rule 15c3-5（市场接入规则）

- **来源（已抓取）：** https://www.ecfr.gov/current/title-17/chapter-II/part-240/subject-group-ECFRc8401dcba174f73/section-240.15c3-5
- **已核验：** 有市场接入的券商须建立事前**信用/资本**与**错单**控制；监管控制（受限证券、授权用户、即时成交回报）；控制权原则上由券商**直接排他**掌握；**至少每年**审查并由 **CEO 证明**。

### Regulation SHO — Rule 201 熔断

- **来源（已抓取）：** https://www.ecfr.gov/current/title-17/chapter-II/part-242/subject-group-ECFR1607681c7b4f78d/section-242.201
- **已核验：** 标的相对前一日上市市场收盘下跌 **10%** 及以上时，交易中心须防止以不高于 NBB 的价格执行/展示卖空，适用于**当日剩余及次日**（含若干例外与 “short exempt”）。

### FINRA Rule 4210 与原 PDT 框架

- **Rule 4210（已抓取）：** https://www.finra.org/rules-guidance/rulebooks/finra-rules/4210 — 现行文本含 **IML（日内保证金水平）** 及 (d)(2) 赤字/补足规则。
- **Regulatory Notice 26-10（已抓取）：** https://www.finra.org/rules-guidance/notices/26-10 — **2026-04-20** 发布；修订 **2026-06-04** 生效，会员可过渡至 **2027-10-20**。明确以日内保证金标准**整体取代**原日内交易保证金制度，包括 **pattern day trader** 认定次数与 **$25,000** 最低权益。教学上把 PDT 作为**历史背景**，把 **IML** 作为核验日下的现行 4210 路径。

### FINRA Regulatory Notice 26-11（IMD / IML 解释）

- **来源（已抓取）：** https://www.finra.org/rules-guidance/notices/26-11 — **2026-05-19** 发布；**2026-06-04** 生效（与 26-10 同日）。
- **已核验：** 发布/更新 Rule 4210 关于新日内保证金标准的解释——包括如何计算 **IMD**（intraday margin deficit）与 **IML**（intraday margin level）、入金、市况变动、强平等示例——并**删除**过时 PDT 日内交易解释。紧挨 26-10 的短更新：26-10 = 规则变更；26-11 = 会员如何落地 IMD/IML + 投资者教育链接。

### FINRA Regulatory Notice 15-09

- **来源（已抓取）：** https://www.finra.org/rules-guidance/notices/15-09 — **2015-03-26**。算法策略督导有效实践：风险评估、代码变更、测试、交易系统监控、合规沟通；并引用 15c3-5 与 Reg SHO。

## 跨境身份边界：税务 / 外汇 / CRS 识字框（中国居民读者）

<Callout type="warn" title="不是税务或法律意见">
以下只是识字：身份、税收居民、受益所有人等条件决定适用规则。本课不判断你的身份、不计算你的税额、不收集税号。2026-11-08 核实。
</Callout>

**W-8BEN 与股息预扣：** [IRS 说明](https://www.irs.gov/instructions/iw8ben)：外国个人把 W-8BEN 交给**扣缴义务人/付款人**，不是交给 IRS；外国人取得的某些美国来源收入（含股息）一般按 30% 征税，协定可降低。[中美税收协定](https://www.irs.gov/pub/irs-trty/china.pdf) 第 9 条：对方居民且为受益所有人时，来源国对股息所征税款不超过毛额的 10%（另见 [IRS 协定说明](https://www.irs.gov/individuals/international-taxpayers/claiming-tax-treaty-benefits)）。**中国国籍 ≠ 中国税收居民 ≠ 自动享受协定**；预扣不是全部税负的最终结算。

**洗售（wash sale，按审阅报告 R25）：** 在适用美国该项所得税规则的情形下，股票/证券亏损出售或处分日前 30 个日历日至后 30 个日历日（含出售日，共 61 个日历日）内，购买/应税交换取得实质相同证券，或订立取得该证券的合同/期权等，可能触发 [IRC §1091](https://uscode.house.gov/us/usc/119-124/t26/s1091/) 的亏损扣除限制。它不是禁止交易，也不是保证免税；一般替代证券成本基础调整等另按 IRS 规定处理（[Pub. 550](https://www.irs.gov/publications/p550)），不能宣称所有情形都仅递延。

**中国个人所得税（按审阅报告 R28）：** 居民个人的境内外所得依中国[个人所得税法](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/201809/t441789.html)规定纳税（在中国境内有住所，或无住所而一个纳税年度内居住累计满 183 天的个人为居民个人）；涉及无住所个人等情形另依适用规定核对，不仅凭国籍判断。财产转让所得适用 20% 比例税率，应纳税所得额一般为转让收入减财产原值及合理费用后的余额；利息、股息、红利所得亦有 20% 法定比例税率，具体减免/协定与所得性质另核。境外已依法实际缴纳的所得税可在规定限额内抵免，非无条件全额抵免；符合规定的超限部分可向后五个纳税年度结转（[公告 2020 年第 3 号](https://www.gov.cn/zhengce/zhengceku/2020-01/22/content_5471604.htm)）。居民个人取得境外所得原则上于次年 3 月 1 日至 6 月 30 日申报。不能由美国预扣完毕推出中国无需申报或无需补税。

**CRS（按审阅报告 R29）：** CRS 是金融账户涉税信息尽职调查与按适用交换关系报送/交换的框架，不是新增证券税种，也不等于所有国家、所有账户自动交换。应按账户所在金融机构及税收居民身份核对适用规则，如实提供税收居民声明；CRS 与美国 FATCA 是不同机制（[税务总局 AEOI 页](https://www.chinatax.gov.cn/chinatax/aeoi_index.html)、[问答](https://www.chinatax.gov.cn/n810341/n810760/c2620533/content.html)）。是否交换不改变依法申报境外所得的义务，不得据此承诺「美股账户隐身/免申报」。

**外汇：** 外汇局上海分局 FAQ（[2026](https://www.safe.gov.cn/shanghai/2026/0402/2412.html)）：个人结汇和境内个人购汇年度便利化额度为每人每年等值 5 万美元。陕西分局 FAQ（[链接](https://www.safe.gov.cn/shaanxi/2018/1204/249.html)）：境内个人额度购汇汇出境外需有真实合法的经常项目用途，**不包括投资境外证券**。所以 5 万美元额度**不是**境外证券投资许可。本课不提供任何汇路、拆分、借名或虚假用途方案。

## ESMA 算法交易监管简报（2026-02-26）— 识字即可

欧盟对照（与 FINRA GenAI / 香港证监会 24EC55 并列）：[ESMA74-1505669079-10311《欧盟算法交易监管简报》](https://www.esma.europa.eu/sites/default/files/2026-02/ESMA74-1505669079-10311_Supervisory_Briefing_on_Algorithmic_Trading_in_the_EU.pdf)（[文档页](https://www.esma.europa.eu/document/supervisory-briefing-algorithmic-trading-eu)），**2026-02-26** 发布。依据 ESMA 条例 Art.29(2) 的**非约束性**趋同工具——**不适用 comply-or-explain**。

**仅识字（不是执照清单，不是 HFT 教程，非法律意见）：**

| 主题 | 简报精神（已抓取 PDF） |
|------|------------------------|
| 算法定义 | 计算机算法决定订单任一参数（价/量/时点/是否发起等）即属算法交易；**人类点击授权 ≠ 自动排除**（若参数已由算法决定） |
| 重大变更复测 | 逻辑/范围/风控/外部依赖变更后复测；**含 ML 重训 / 自适应能力**（一系列小重标定也可累积成重大变更） |
| 压力测试 | 系统应能承受约 **2×** 过去 **6 个月**峰值报文/成交量（RTS 6 Art.10 精神） |
| PTC | **硬阻断**满足强制要求；**软阻断**强烈建议；母/子单累计校验 |
| 外包 | 使用第三方算法/软件时，**投资公司仍负全责**；合同不能转移监管责任 |
| AI Act + 自评 | 与 AI Act 交互需纳入治理；RTS 6 **Art.9** 年度自评/验证精神——把 AI 用法写进自评 |

与亚洲同侪（SFC 24EC55、FINRA GenAI）一起读：**某司法辖区撤回某提案 ≠ 其他辖区无义务。**

## 常见错误 / 陷阱

- 假定 PDA 撤回消灭了全部 AI/建议义务（FY2026 仍列 Emerging FinTech）。
- 把 FINRA GenAI 主题当成交易执照或产品 alpha。
- 把香港证监会（SFC）通函 24EC55 当成交易执照，而非持牌法团期望。
- 把 ESMA 简报当成可勾选的执照清单或 HFT 操作手册。

1. 用自媒体阈值代替交易所/证监会文本。
2. 把工作人员声明当成委员会终局规则。
3. 2026+ 仍只讲 PDT/$25k、不提 Notice 26-10 / 26-11 IMD/IML 的取代。
4. 把证券〔2024〕8 与期货〔2025〕12 混为一谈——市场与交易所不同。
5. 用本课程给人做个性化投顾。
6. 不标注「核验日期」。
7. 把现行交易规则套到全部历史回测上；把仍暂缓实施的条文当作已生效。
8. 只凭交易日期断言券商/账户已迁移到新日内保证金（2026-06-04 至 2027-10-20 有迁移期）；把 5 万美元购汇额度当成境外证券投资许可；以为美国预扣完毕就不用在中国申报。
