## 学习目标

本课（约 **10 学时**：设计 3h + 运行/日志 6h + 模板 1h）在**合成数据**上建立纸面闭环：信号→目标→模拟成交→日志→对账→漂移指标，以及熔断与实盘−回测缺口的数值分解。前置：`risk-systems-lab`。

**课内目标：** CSV/模拟撮合；产出日报日志；说明纸面验证的是流程而非 alpha。

**必须教会：** 纸面期间冻结策略版本；不按盈亏改规则；对账与异常日志；把实盘−回测缺口分解为滑点、成交、延迟、数据；熔断是工程。**禁止真实券商下单代码**——本站保持仅供学习。

<Callout type="info" title="仅供学习 — 非投资建议">
合成行情与模拟成交。此处不连接任何实盘券商。
</Callout>

## 参数

- 合成序列：400 交易日；信号 `sign(mom20)`；波动目标年化 10%；冻结 `VERSION=mom20_vt_v1.0.0`
- 研究对照：下一根收盘成交，成本 `5 bps · |Δw|`
- 纸面对照：开盘成交，延迟 1–2 根，滑点 `2 + 8·|Δw|` bps，约 8% 部分成交
- 熔断：数据缺口→空仓；回撤软 4% / 硬 8%；总敞口 ≤ 1.5

## 纸面循环（无券商）

`examples/p7/01_paper_trading_loop.py` 运行 ≥360 个交易日：每日记录版本、目标、仓位、权益、回撤与备注。成交与熔断事件写入 `examples/p7/data/`。

**纸面验证什么：** 接线（信号→仓位→成交→账本）、熔断行为、日志纪律——**不是**信号一定有优势。

![纸面权益](/p7/paper_equity.png)

## 对账与漂移

实验账本与权益序列绝对误差 ≈ 0。漂移示意：Spearman(mom20, fwd_ret) 前期 ≈ −0.13、后期 ≈ −0.09（delta ≈ +0.04）——即使 IC 很弱也要监控分布漂移。

## 实盘 vs 回测缺口（数值）

同一信号；阶梯中只改摩擦（收益序列固定）：

| 阶段 | 累计收益（实验） | 相对研究缺口 |
|------|------------------|--------------|
| research_bt | ≈ −0.030 | — |
| +latency | ≈ +0.015 | 时点可正可负 |
| +slip | ≈ −0.008 | 结构性成本 |
| +partial | ≈ −0.016 | 部分/未成交 |

结构：研究 5 bps·\|Δw\|；纸面有换仓日的均滑点约 3 bps（公式仍为 `2+8·|Δw|`）；部分成交把成本乘 1/0.85。

![缺口阶梯](/p7/live_bt_gap.png)

## 熔断（代码演示）

单元用例：

- `dd=-0.01` → ok
- `dd=-0.05` → `dd_derisk`（降仓）
- `dd=-0.09` → `dd_kill`（空仓）
- `gap=True` → `data_gap`
- `target=2.5` → `gross_clip` 至 1.5

## 前瞻警告

- 信号只用过去收盘；勿用当日未来收益定仓
- 纸面成交用开盘/延迟——勿在中途悄悄换成研究成交
- 整个纸面窗口冻结 `VERSION`

## 常见错误 / 陷阱

1. 看到纸面盈亏就改信号规则。
2. 把纸面夏普当成实盘证明。
3. 把研究成交混进纸面账本。
4. 成交 CSV 与权益不对账。
5. 在学习仓库里塞券商 API / 下单路由。
